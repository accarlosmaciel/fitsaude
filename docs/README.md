# 🏋️ FitSaúde – Documentação do Projeto

Bem-vindo à documentação oficial do **FitSaúde**, um sistema web *mobile-first* para acompanhamento de treinos, gestão de saúde, geração de relatórios em PDF, análise de desempenho e assistente virtual com inteligência artificial.

- ⚡ [**Funcionalidades**](FUNCIONALIDADES.md) — Detalhamento das telas, rotinas de treino, gerador de PDF e FitBot IA.
- 📊 [**Estado Atual do Projeto**](ESTADO_ATUAL.md) — Status de desenvolvimento, arquitetura, persistência de dados e oportunidades futuras.

---

## 🚀 Como Executar o Projeto

1. Obtenha os arquivos do projeto no seu ambiente local.
2. Abra o arquivo [`index.html`](../index.html) diretamente em qualquer navegador moderno (Chrome, Edge, Firefox, Safari).
3. **Sem necessidade de build ou backend**: O projeto executa 100% no navegador (Client-Side).

---

## 🎨 Filosofia de Design & UX

- **Estética:** Dark Mode com visual Cyber/Glassmorphism (`#060608` background com tons neon crimson, cyan, purple e emerald).
- **Layout:** Mobile-First App Shell com barra de navegação inferior (*Bottom Navigation Bar*).
- **Interatividade:** Micro-animações, seletores de modalidade/dia e atualizações de tela dinâmicas em tempo real sem recarrego de página.
